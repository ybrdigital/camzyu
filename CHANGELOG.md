## [1.0.0] - 2026-11-17

### Added
- **Project Rebranding**: Officially transitioned product identity to **Camybr**.
- **Camybr Windows Plugin**: Released standalone Windows virtual webcam and virtual audio microphone with system-wide DirectShow driver compatibility for Zoom, Google Meet, Microsoft Teams, Discord, Skype, OBS Studio, and other Windows desktop applications.
- **High-Performance Hardware Decoding**: Low-latency video pipeline utilizing FFmpeg (`libavcodec`) with real-time planar YUV rendering.
- **DirectShow Virtual Microphone**: 48 kHz stereo audio stream captured directly from the Android phone microphone into Windows audio devices.
- **Automatic Device Discovery**: Instant subnet beacon listener for zero-configuration pairing over local Wi-Fi and wired USB tethering.
- **Freeware Distribution**: Windows Plugin is distributed as 100% free software (closed-source freeware, no watermark on PC).
- **Android App Support**: Seamless integration with the Camybr Android mobile app (`com.briyoom.camybr`).
