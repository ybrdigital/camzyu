## [1.0.0] - 2026-11-17

### Added
- **Project Rebranding**: Officially transitioned product identity to **Camzyu**.
- **Camzyu PC Plugin**: Released standalone PC virtual webcam with system-wide DirectShow driver compatibility for Zoom, Google Meet, Microsoft Teams, Discord, Skype, OBS Studio, and other desktop applications.
- **High-Performance Hardware Decoding**: Low-latency video pipeline utilizing FFmpeg (`libavcodec`) with real-time planar YUV rendering.
- **Automatic Device Discovery**: Instant subnet beacon listener for zero-configuration pairing over local Wi-Fi and wired USB tethering.
- **Freeware Distribution**: PC Plugin is distributed as 100% free software (closed-source freeware, no usage limitations).
- **Android App Support**: Seamless integration with the Camzyu Android mobile app (`com.briyoom.camzyu`).
