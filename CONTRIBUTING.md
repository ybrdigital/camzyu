# Camzyu - Maintenance Policy & User Feedback Guidelines

## 1. Project Ownership and Maintenance

**Camzyu** (including the Camzyu PC Plugin, Camzyu Android Mobile Application, and website) is designed, developed, and maintained by **Yash Rayjada (YBR Digital)**.

Camzyu PC Plugin is distributed as **free proprietary software (freeware)**. The source code is closed-source and owned exclusively by YBR Digital.

---

## 2. Pull Requests Policy

Official development of Camzyu software is managed exclusively by the author.

- **Pull Requests**: Because the codebase is proprietary freeware, this repository does not accept external pull requests or code merges.
- **Why this policy exists**: Maintaining a single, focused codebase for the desktop plugin, mobile client, and virtual driver architecture ensures strict security, stability, and direct architectural cohesion.

---

## 3. Bug Reports & Feature Requests

Users, creators, streamers, and remote professionals are warmly welcome to submit bug reports, compatibility feedback, and feature suggestions through [GitHub Issues](https://github.com/ybrdigital/camzyu/issues).

When reporting an issue, please include:
- OS version (e.g., Windows 11 24H2 64-bit, macOS, Linux)
- Target software where Camzyu was used (e.g., Zoom, Google Meet, Microsoft Teams, OBS Studio)
- Android phone model and Android version
- Connection mode (5 GHz Wi-Fi or USB Tethering)
- Steps to reproduce the issue
